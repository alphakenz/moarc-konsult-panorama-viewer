# Moarc Konsult Panorama Viewer

Recommended GitHub repository name: `moarc-konsult-panorama-viewer`

This is the standalone GitHub Pages version of the Moarc Konsult panorama viewer. It uses the 2:1 equirectangular image in `kitchen-panorama.png` and loads Pannellum from jsDelivr.

The viewer includes room presets, auto-rotation, ambient music, fullscreen view, zoom controls, and sharing. Music is started by the visitor through the music button because browsers block unexpected autoplay.

Music credit: “Valley Sunset” by Alejandro Magaña (A. M.), used under the [Mixkit Stock Music Free License](https://mixkit.co/license/#musicFree). The track is bundled locally as `ambient-panorama.mp3`.

The `image-gallery` folder is an alternative multi-image version and is intentionally excluded from this standalone upload package.

## GitHub Pages

1. Upload the contents of this folder to the root of a GitHub repository.
2. In GitHub, open **Settings → Pages**.
3. Select **Deploy from a branch**, choose the default branch and the `/ (root)` folder, then save.
4. Open the Pages URL GitHub provides.

The `image-gallery` folder is an alternative multi-image gallery and is not required for this standalone viewer.
